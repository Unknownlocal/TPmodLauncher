Guest CPython source: https://github.com/dicej/cpython/tree/v3.14.0-wasi-sdk-30
notices/mod-runtime/LICENSE.PythonGuest.txt preserves that source's LICENSE.
The toolchain's guest Python 3.14 is separate from the launcher interpreter.
The distributed interpreter uses that upstream WASI-enabled fork, compiled to
WebAssembly and preinitialized with the fixed runner and frozen Python sources.
Its WASI imports use denial stubs. This repository makes no additional CPython
source changes. This summary also accompanies the runner as NOTICE.PythonChanges.txt.

the component-specific terms referenced by those overview files.

Guest CPython's original third-party inventory is retained as
notices/mod-runtime/LICENSE.PythonThirdParty.rst, alongside Expat, zlib, HACL,
libmpdec and SQLite licence/copyright notices for its native dependencies.
NOTICE.CPythonNative.txt, NOTICE.HaclHeaders.txt and NOTICE.WasiLibcSources.txt

Guest runtime support also incorporates Rust standard-library and runtime crate
code. notices/mod-runtime/COPYRIGHT.RustStd.html retains the complete original
Rust 1.98.1 library copyright inventory; LICENSE.Rust.txt retains its MIT licence.
Official source: https://github.com/rust-lang/rust/tree/1.98.1
Separate upstream licence texts cover anyhow, once_cell, num-bigint/num-integer/
num-traits, PyO3/PyO3-FFI, libc, portable-atomic, wit-bindgen, wit-dylib-ffi and
Unicode data. The fixed notice inventory is listed in mod_runtime/bundle.py and
recorded, with hashes, in every distributed runner's bundle.json. Complete
upstream files are preserved unchanged; upstream-source NOTICE files retain the applicable
upstream licence/copyright blocks. The runner builder is a developer dependency;
player startup uses only the prebuilt artifact and its retained sources/notices.
